# Dataset Information

## Dataset Used

This project uses the PaySim dataset for financial fraud detection.

PaySim is a synthetic financial transaction dataset used for analyzing financial transactions and identifying fraudulent activities.

## Dataset Usage

The dataset is used for:

- Transaction-level fraud detection
- Data preprocessing and feature engineering
- Handling class imbalance using SMOTE
- Machine Learning model training and evaluation
- Financial transaction network analysis
- Graph Neural Network (GraphSAGE) analysis
- Explainable AI using SHAP
